## 🚀 Featured Projects

### 🛒 Ecommerce Customer Churn Analysis Dashboard
> **Stack:** MySQL · Power BI · CSV

Built a full churn analysis pipeline for an ecommerce business — from raw CSV to actionable Power BI dashboard. Analyzed customer demographics, subscription tiers, purchase behavior, and support activity to pinpoint who's at risk and why.

**Key insights surfaced:**
- Churn rate by subscription type (Basic → Platinum)
- High-risk customer identification via support tickets + recency signals
- City- and gender-level segmentation for targeted retention

📁 [View Repository](https://github.com/sathish-2424/Ecommerce-Customer-Churn-Analysis-Dashboard)

---

### 🏥 Healthcare Patient Analytics Dashboard
> **Stack:** MySQL · Power BI · Tableau · CSV (55,501 records)

A dual-platform analytics build (Power BI + Tableau) on a large patient dataset. Covers revenue patterns, hospital performance, and patient flow — the kind of operational visibility that supports smarter clinical decisions.

**Dashboard KPIs include:**
- Total revenue, avg. billing, avg. length of stay
- Admission type breakdown & doctor-level billing
- Medical condition trends by age and gender

📁 [View Repository](https://github.com/sathish-2424/Healthcare-Patient-Analytics-Dashboard)

---

### 🎮 Global Video Game Sales Analytics Dashboard
> **Stack:** MySQL · Power BI · CSV

Dug into the classic `vgsales` dataset to uncover which platforms, genres, and publishers dominated global sales. Full SQL analytics workflow with window functions, trend analysis, and regional comparisons — wrapped up in a Power BI dashboard.

**Explored angles:**
- Top 10 best-selling games of all time
- Genre vs. platform sales breakdowns (NA, EU, JP, Other)
- Yearly sales trends + publisher rankings via window functions

📁 [View Repository](https://github.com/sathish-2424/Global-Video-Game-Sales-Analytics-Dashboard)
