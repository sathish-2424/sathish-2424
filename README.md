## 🚀 Featured Project

### 🖥️ System Monitoring Tool
> **Stack:** Python · psutil · JSON

A lightweight Python script that checks CPU, memory, and disk usage at regular intervals and raises an alert the moment usage crosses a configured threshold — the kind of basic health monitoring every server and cloud instance needs.

**Key features:**
- Real-time CPU, memory, and disk monitoring with live console output
- Alerts and activity logged to a file (`log.txt`)
- Configurable thresholds and check interval through `config.json`
- Falls back to built-in defaults if the config is missing or invalid
- Exits gracefully on Ctrl+C

📁 [View Repository](https://github.com/sathish-2424/System-Monitoring-Tool)
